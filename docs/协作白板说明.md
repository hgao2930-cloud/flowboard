# 协作白板设计

## 三类状态

| 状态                               | 所属对象                    | 是否持久化       |
| ---------------------------------- | --------------------------- | ---------------- |
| 节点、正文、颜色、位置和连线       | Y.Doc 的 nodes / edges      | MySQL 的 y_state |
| 昵称、光标、正在编辑/拖动的节点    | WebsocketProvider.awareness | 否               |
| 选择、视口、详情面板、动画中间位置 | Vue 页面                    | 否               |

每个客户端房间会话拥有一份 Doc 和 provider。关闭 BroadcastChannel，同浏览器标签页也通过服务器同步。节点使用嵌套 Y.Map；标题与正文分别更新，位置将 x/y 一起写入。普通字符串同字段并发通过 Yjs 收敛，不是逐字符协同文本编辑。

## 文件职责

- `frontend/src/collaboration/document.ts`：共享图、字段更新、投影、连线约束和本地 UndoManager。
- `frontend/src/collaboration/session.ts`：Doc、provider、Awareness 的创建、回调和销毁。
- `frontend/src/collaboration/remoteMotion.ts`：远端显示位置的短过渡，不访问文档或网络。
- `frontend/src/collaboration/deletion.ts`：根据在线编辑提示筛选可删除节点和关联边。
- `frontend/src/views/BoardView.vue`：画布、工具栏、详情、连接/保存状态和导出。
- `frontend/src/views/HomeView.vue`：创建、加入、导入和最近访问。
- `frontend/src/rooms/`：HTTP 接口、管理凭证、本机记录与邀请链接解析。
- `backend/src/server.js`：HTTP 路由、删除凭证、WebSocket 升级前的房间检查。
- `backend/src/room-runtime.js`：加载、保存排队、重试、释放、删除与关闭。
- `backend/src/mysql-store.js`：连接池与 SQL 操作。
- `shared/boardFile.mjs`：前后端共用文件协议，显式选择可导入字段。

## 房间生命周期

1. POST /api/rooms：生成 UUID 和 256 bit 随机管理凭证，将空 Yjs 文档及房间资料写入同一行，提交成功才响应。
2. 进入白板先 GET 检查房间；直接访问和刷新也执行检查。WebSocket 升级前加载数据库文档，同房间并发进入复用同一次加载。
3. 完成连接与首次同步后挂载画布。首次失败有超时与重试入口；进入后的普通断线保留本地文档并自动重连。
4. 修改即时同步；第一次变更起默认两秒固定窗口保存完整 Yjs 快照，不随持续拖动无限延期。
5. 最后一端退出后保存再释放文档、Awareness 和定时器。保存期间重新进入会复用同一实例。
6. 删除时验证管理 token，冻结协议写入，等待在途保存，再删除整行记录；成功后以关闭码 4004 通知在线端退出。

服务端关闭依赖的默认 persistence，自己控制加载和销毁时机，避免异步加载尚未结束就广播空文档，或异步写库与默认释放交错。

## 数据库

表 `flowboard_rooms`：id、title、management_hash、y_state、revision、created_at、updated_at。

`y_state` 是完整 Yjs 二进制快照，保留 CRDT 合并所需信息，不是仅存普通节点 JSON。房间资料和图在同一行，删除不留下孤立文档。代价是每次保存编码整张图，不能直接通过 SQL 查询节点正文。

同一房间保存串行执行；保存期间的新修改随后再保存。UPDATE 附带递增 revision 条件，不使用 UPSERT，避免迟到保存覆盖新状态或重新创建已删除房间。revision 是持久化顺序，不是 CRDT 冲突处理算法。

写库失败默认在 1、2、4 秒重试，耗尽后保留未保存内存文档并停止接受更多修改，可手动重试。关闭信号默认最多等待 12 秒保存；强杀、断电不能保证最终保存。前端每四秒查询保存状态，显示的是服务端快照状态，不承诺本机尚未发送的修改已落库。

## 协作显示与操作

- 本地拖动直接更新；远端画布更新合并到 requestAnimationFrame，每个位置目标用约 70ms 过渡，到达后停止调度。初次加载和本地撤销不做过渡。
- 本地接管拖动、删除或页面销毁会清理动画。动画只修改显示坐标，不回写 Y.Doc。连线随节点位置更新，不反复重建未变化的连线数据。
- 光标位置转换为画布坐标，通过 Awareness 约每 50ms 发布一次，显示使用 55ms CSS 过渡。
- 文本随输入按字段同步；输入法组合过程在本地等待确认。UndoManager 仅跟踪本客户端操作，一次拖动作为一个撤销步骤。
- Awareness 编辑提示用于防误删，不是服务端锁。远端同时删除仍可能发生，过期编辑不会重建节点；悬空边仅在显示投影中被过滤。

## 管理凭证与文件

管理凭证保存在 localStorage，独立于最近访问；同浏览器普通窗口共享。服务端只保存 SHA-256 哈希，DELETE 通过 X-Room-Management-Token 发送原始凭证。缺失返回 401，不匹配返回 403。昵称、clientID 和客户端自报 owner 不参与授权。

JSON 导出只保存格式版本、名称、节点和连线，读取共享文档而非动画位置。导入最多 1 MiB，校验版本、节点 ID、有限坐标、颜色与引用关系；新房间和完整初始文档同次写入数据库，并签发新的管理凭证。不包含或恢复在线成员、凭证和撤销历史。

## 运行边界与验证

开发使用 /api 和后端 3000；生产前端根路径为 /flowboard/，Nginx 将 /flowboard/api/ 转为 /api/，将 /flowboard/ws/ 转为 /。生产后端通过 HOST=127.0.0.1 只监听本机。

单消息默认上限为文档上限加 64 KiB，容纳离线累计更新。消息超限关闭 1009，文档超限关闭 4009，客户端停止自动重连并保留内容供导出。文档超限不无限重试，也不会自动裁剪；管理者仍可删除。

默认后端测试使用存储替身。独立 MySQL 自动测试必须显式配置，不能当作已经执行。线上正常重启恢复和导入落库已经单独验收；实时交互由用户体验确认。完整验证记录、已知限制见根目录 README。
